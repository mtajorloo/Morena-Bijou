# Moréna logo assets

| File | Use |
| --- | --- |
| `morena-logo-black.svg` | Full logo (emblem + wordmark), black, transparent background. For light backgrounds. |
| `morena-logo-white.svg` | Same logo in white. For dark backgrounds (the site's default). |
| `morena-emblem-black.svg` | Shield emblem only, black. Good for favicons, nav, social avatars. |
| `morena-emblem-white.svg` | Shield emblem only, white. |
| `morena-logo-gold-transparent.png` | The original gold artwork with the navy background removed (alpha channel). |

The SVGs are pure vector paths (no fonts, no embedded images), so they scale
to any size and can be recoloured by changing the single `fill` attribute on
the `<g>` element, or from CSS when inlined.

Wordmark typefaces: Cinzel (MORÉNA) and Montserrat (FINE JEWELRY), converted
to outlines.
